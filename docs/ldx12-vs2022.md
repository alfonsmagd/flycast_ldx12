# Flycast + Ldx12: Visual Studio 2022

Este fork incorpora solamente la biblioteca Ldx12 como dependencia de compilacion
y enlace. No implementa un renderizador Direct3D 12 ni cambia los renderizadores
existentes.

## Abrir y compilar

Requisitos: Windows, Visual Studio 2022 con Desarrollo para el escritorio con C++,
Windows SDK y CMake 3.24 o posterior. La integracion inicial usa MSVC y x64.

```powershell
git clone --recurse-submodules https://github.com/alfonsmagd/flycast_ldx12.git
cd flycast_ldx12
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DUSE_DX9=OFF -DFLYCAST_ENABLE_LDX12=ON
cmake --build build --config Debug --target flycast --parallel
cmake --build build --config Release --target flycast --parallel
```

Abre `build/flycast.sln` en Visual Studio 2022 y selecciona `flycast` como proyecto
de inicio. Tambien puedes ejecutar `shell/windows/generate_vs_project.bat` para
generar y abrir la solucion.

El proyecto `Ldx12` aparece en `Dependencies/Ldx12` y se compila automaticamente
al compilar Flycast. Sus cabeceras estan disponibles en `core/deps/LightDX12/Ldx12/include`
y su biblioteca se enlaza con Flycast y las bibliotecas del sistema Direct3D 12.
No se compilan ejemplos, tests, App, Utils ni la integracion ImGui de Ldx12.

Ldx12 se compila como C++20. En esta fase se conservan las opciones de compilacion
de las fuentes existentes de Flycast. Al introducir codigo que incluya las
cabeceras de Ldx12, ese codigo debera compilarse como C++20.

La dependencia esta fijada por Git a una revision concreta de
`https://github.com/alfonsmagd/LightDX12.git`. Para recuperar todos los submodulos:

```powershell
git submodule update --init --recursive
```

`FLYCAST_ENABLE_LDX12` esta activado por defecto para Windows de escritorio con
MSVC x64 y desactivado para otras plataformas. Se puede desactivar explicitamente
con `-DFLYCAST_ENABLE_LDX12=OFF`.
